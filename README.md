# James Kinyua | Senior Software & AI Engineer Portfolio

A premium, interactive developer portfolio and CV website designed with a slate-dark modern aesthetic, responsive grid layouts, custom scroll animations, and official developer technology logos.

🚀 **Live Site:** [https://jaykay24.github.io/cv/](https://jaykay24.github.io/cv/)

---

## 🛠️ Tech Stack & Features

- **Frontend & Styling:** HTML5, Tailwind CSS, custom modern CSS animations, and premium glassmorphism gradients.
- **Iconography:** Official colored technology logos loaded via Devicon CDN alongside custom inline SVGs.
- **Scroll Effects:** Progressive CSS scroll-driven keyframe animations with a native JavaScript `IntersectionObserver` fallback for older browsers.
- **Responsive Layout:** Dynamic grid systems optimized for mobile, tablet, and wide desktop screen viewports.

## 💻 Running Locally

Since this is a fully static client-side application, you can run it locally without any compiler or package manager:

1. Clone this repository:
   ```bash
   git clone git@github.com:JayKay24/cv.git
   cd cv
   ```

2. Open the file in your browser:
   * **Double-click** `index.html` to open it directly.
   * **Or serve it locally** using Python (recommended for testing path links):
     ```bash
     python3 -m http.server 8000
     ```
     Then navigate to `http://localhost:8000`.
